\## Scope

This document defines the configuration requirements for a specific
workstation deployment.

It supplements the Commissioning Manual and should be customised for
each machine without modifying the operational procedures or the
Knowledge Governance Framework.

\## Design Principle

A Workstation Profile describes a specific deployment.

It should evolve as hardware, software, and operational requirements
change while remaining consistent with the Knowledge Governance
Framework and Commissioning Manual.

The profile records \*\*what\*\* a workstation is expected to contain;
the Commissioning Manual defines \*\*how\*\* it is deployed; and the
Knowledge Governance Framework defines \*\*why\*\* the system is managed
in this manner.
